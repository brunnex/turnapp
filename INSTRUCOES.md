# 📱 COMO USAR NO iPHONE - PASSO A PASSO

## ✅ O QUE VOCÊ PRECISA:
- iPhone com Safari
- 2 minutos

---

## 🚀 INSTRUÇÕES SUPER SIMPLES:

### PASSO 1: COLOCAR OS FICHEIROS ONLINE

Você tem 3 ficheiros:
- `index.html`
- `TurnosApp.jsx` 
- `sw.js`
- `manifest.json`

**ESCOLHA UMA OPÇÃO:**

---

#### OPÇÃO A: NETLIFY DROP (MAIS FÁCIL) ⭐

1. Abra este site no computador: **https://app.netlify.com/drop**

2. Arraste os 4 ficheiros para a janela

3. Vai aparecer um link tipo: `https://meusite.netlify.app`

4. **COPIE ESTE LINK!**

---

#### OPÇÃO B: GITHUB PAGES

1. Crie conta grátis em **github.com**
2. Crie repositório "turnos-app"
3. Faça upload dos ficheiros
4. Vá em Settings > Pages > Enable
5. Link: `https://seu-usuario.github.io/turnos-app`

---

### PASSO 2: ABRIR NO iPHONE

1. **Envie o link para o seu iPhone** (WhatsApp, Email, etc)

2. **Abra o link no Safari** (importante: tem que ser Safari!)

3. A app vai abrir no browser

---

### PASSO 3: ADICIONAR AO ECRÃ INICIAL

1. **Clique no botão de Partilhar** (quadrado com seta ⬆️) no fundo do Safari

2. **Scroll para baixo** até ver "Adicionar ao Ecrã Inicial"

3. **Clique** em "Adicionar ao Ecrã Inicial"

4. **Confirme** (pode mudar o nome se quiser)

---

### PASSO 4: USAR A APP! 🎉

- Vai aparecer um **ícone azul** no ecrã inicial
- **Clique** no ícone
- Abre como **app nativa** (sem barra do Safari!)
- **Funciona offline**
- **Dados guardados** no telefone

---

## 🎯 RESUMO RÁPIDO:

1. Upload ficheiros → Netlify Drop
2. Abrir link → Safari no iPhone  
3. Partilhar → Adicionar ao Ecrã Inicial
4. Usar como app normal!

---

## ❓ PROBLEMAS?

**Não funciona?**
- Certificar que abriu no **Safari** (não Chrome/Firefox)
- Verificar que os 4 ficheiros foram enviados
- Tentar recarregar a página (puxar para baixo)

**Precisa de ajuda?**
- Mande mensagem com print do erro

---

## 📧 MÉTODO ALTERNATIVO (SEM HOSPEDAR):

Se não quiser hospedar online, pode:

1. Enviar os ficheiros por email para si mesmo
2. Abrir no iPhone > Ficheiros
3. Clicar no `index.html`
4. Mas assim **não funciona offline** e **não guarda dados**

**Por isso recomendo Netlify Drop!** ⭐
